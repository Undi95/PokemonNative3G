# Classement à la main des fonctions de même nom dans RF et la fusion, au corps différent (tools/carto_divergentes.py,
# docs/carto/divergentes-tri.md). Une ligne par fonction : NOM CATÉGORIE PREUVE. Catégories :
#   même       même code, une fois lue (une écriture que l'outil ne ramène pas : struct réorganisée, noms d'index)
#   émeraude   Émeraude fait tout ce que fait RF, et plus (Pyramide, Colline, Île Lointaine…) : rien de Kanto perdu
#   kanto      la fusion a déjà la partie propre à Kanto (variante Kanto, test de région, données de RF)
#   variante   détail du code commun différent dans RF : Émeraude gardée (règle du 2026-11-02) ; les variantes
#              visibles sont dans docs/VARIANTES-RF.md
#   journal    journal (« Précédemment ») ou aide L/R de RF : écartés (Kanto = post-game, 2026-11-02)
#   link       link : celui d'Émeraude dans les deux régions (caché, LINK_ENABLED)
#   porter     à porter (un comportement de RF qui manque à Kanto)
#
