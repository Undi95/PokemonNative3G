PokemonNative3G

Chargement…

Clavier : flèches, A = Z, B = X, Start = Entrée, Select = Retour arrière, L = A, R = S, accélérer = Espace (la touche où la lettre est écrite, AZERTY comme QWERTY). Manette et écran tactile aussi.

La partie est gardée dans ce navigateur. Exportez-la de temps en temps : c'est le même fichier .sav que sur PC et Android.

Touches

« Changer », puis la touche voulue (Échap : annuler). Une touche est celle où la lettre est écrite ; les touches sont gardées dans ce navigateur.
